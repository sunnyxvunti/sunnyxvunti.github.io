# Sanjeev Raila — Personal Portfolio

This public repository hosts the professional portfolio at **https://sunnyxvunti.github.io** once GitHub Pages is enabled.

The website source belongs at the root of the `main` branch:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `projects/`

GitHub Pages: repository **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Do not upload a ZIP as the site; extract it and upload the contained files and folders while retaining the paths.
